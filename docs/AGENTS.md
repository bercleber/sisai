Contexto: um pequeno projeto de cadastro de Clientes, possuirá backend e frontend. Apenas uma tela.
O projeto deve possuir uma pasta para o backend e outra para o frontend.

Frontend:

- deverá ser feito utilizando apenas HTML, CSS e JavaScript.
- deve ser responsivo para mobile e desktop.
- os campos do formulário devem ser validados no frontend.

Backend:

- deverá ser feito em Node utilizando Express.
- Sera uma aplicação REST.
- Deverá validar os dados de entrada vindos do usuário.

Database:

- MariaDB local.
